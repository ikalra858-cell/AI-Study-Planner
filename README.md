# AI Study Planner

AI Study Planner is a lightweight interactive web application that helps students create personalized study plans based on their subject, available daily study time, difficulty level, and the number of days remaining before an exam. By taking these inputs into account, it generates a structured schedule with dedicated study, revision, practice, and break sessions — giving students a clear and manageable path to exam day.

> **Note:** The planning logic is implemented entirely using JavaScript rules and does not rely on any external AI API or machine learning model.

---

## ✨ Features

- Personalized study plan generation based on user inputs
- Difficulty-based session recommendations
- Balanced mix of study, revision, practice, and break sessions
- Interactive session completion tracking
- Dynamic progress indicator
- Personalized study tips tailored to difficulty level
- Form validation with clear feedback
- Responsive design that works across screen sizes

## ⚙️ How It Works

1. The user enters their subject, available daily study time, difficulty level, and the number of days remaining before their exam.
2. The application processes these inputs using JavaScript-based planning logic to determine an appropriate session structure.
3. A structured study plan is generated, broken down into study, revision, practice, and break sessions across the available days.
4. Users can mark individual sessions as completed and track their overall progress through a dynamic progress indicator.

No installation or external dependencies are required.
